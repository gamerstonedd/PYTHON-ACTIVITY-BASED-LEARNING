Test Case 1: CSE applicant meets the threshold

Write a Python program to check whether an applicant named Anil is eligible for CSE admission when his Mathematics, Physics, and Computer Science marks are 82, 76, and 88 respectively. The minimum aggregate required for CSE is 70%.

Test Case 2: ECE applicant meets the threshold

Write a Python program to determine whether Bhavya is eligible for ECE admission when her Mathematics, Physics, and Computer Science marks are 70, 68, and 72 respectively. The minimum aggregate required for ECE is 65%.

Test Case 3: EEE applicant meets the threshold

Write a Python program to determine whether Divya is eligible for EEE admission when her Mathematics, Physics, and Computer Science marks are 65, 60, and 70 respectively. The minimum aggregate required for EEE is 60%.

Test Case 4: CSE aggregate below the threshold

Write a Python program to check whether Esha is eligible for CSE admission when her Mathematics, Physics, and Computer Science marks are 69, 72, and 75 respectively. The minimum aggregate required for CSE is 70%.

Test Case 5: Subject mark below the minimum

Write a Python program to determine whether Gopal is eligible for EEE admission when his Mathematics, Physics, and Computer Science marks are 49, 80, and 80 respectively. Each subject must have at least 50 marks, and the EEE aggregate requirement is 60%.

Test Case 6: Exactly at the CSE threshold

Write a Python program to check whether Hari is eligible for CSE admission when he scores 70 marks in each of the three subjects. The minimum aggregate required for CSE is 70%.

Test Case 7: Exactly at the ECE threshold

Write a Python program to check whether Isha is eligible for ECE admission when she scores 65 marks in each of the three subjects. The minimum aggregate required for ECE is 65%.

Test Case 8: Exactly at the EEE threshold

Write a Python program to check whether Jaya is eligible for EEE admission when she scores 60 marks in each of the three subjects. The minimum aggregate required for EEE is 60%.

Test Case 9: Ranking based on Mathematics marks

Write a Python program to rank two eligible CSE applicants, Kiran and Latha, when their marks are (70, 70, 70) and (75, 65, 70), respectively. If their aggregate percentages are equal, the applicant with higher Mathematics marks must receive the higher rank.

Test Case 10: Ranking based on alphabetical order

Write a Python program to rank two eligible ECE applicants, Zoya and Aarav, who have identical marks of 70 in Mathematics, 68 in Physics, and 72 in Computer Science. When all ranking criteria are equal, the applicant whose name comes first alphabetically must receive the higher rank.
